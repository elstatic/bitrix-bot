# AGENTS Instructions

## Setup (first run)

Перед запуском сетапа агент должен проверить `.env` в корне репозитория.

Если в `.env` уже есть `BITRIX24_WEBHOOK_URL`, то сетап **не нужен**.

`PROJECTS_DIRS` — **опционально**. Если его нет, это нормально: сканирование проектов просто пропускается.

Если `BITRIX24_WEBHOOK_URL` отсутствует или `.env` отсутствует, агент должен **запустить/предложить** скилл `setup-env` для настройки окружения.

## Onboarding (first run)

При первом запуске агент должен коротко и простым языком рассказать, что он умеет, и сделать обзор скиллов. Объяснение должно быть для нетехнических пользователей, без терминов и жаргона.
