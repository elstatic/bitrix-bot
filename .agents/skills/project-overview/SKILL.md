## Оригинальная инструкция

# Project Overview Skill

Skill для получения «взгляда сверху» на клиентский проект: трафик, конверсии, источники, задачи, красные флаги.

**Read-only** — skill только читает данные из Яндекс.Метрики и Битрикс24.

## Авторизация

### Битрикс24

Вебхук хранится в `.env` в переменной `BITRIX24_WEBHOOK_URL`.

### Яндекс.Метрика

OAuth-токен хранится в `.env` в переменной `YANDEX_METRICA_TOKEN`.

Если токен не задан — **всегда показывай ссылку** для получения и продолжай работу (скрипт пропустит Метрику):

> Для данных Яндекс.Метрики нужен OAuth-токен. Без него отчёт будет только по задачам Битрикс24.
>
> Получить токен:
> 1. Перейдите по ссылке: `https://oauth.yandex.ru/authorize?response_type=token&client_id=7368452574844188a8dcc74b68dfa903`
> 2. Авторизуйтесь и скопируйте токен из URL
> 3. Добавьте в `.env`: `YANDEX_METRICA_TOKEN=<ваш_токен>`

## Алгоритм

### Шаг 1: Определить проект

Пользователь указывает название проекта. Запусти поиск:

```bash
python3 .claude/scripts/project_overview/main.py --find "<название>"
```

Скрипт вернёт JSON с найденными счётчиками Метрики и группами Битрикс24.

**Если найдено одно совпадение** в каждой системе — подтверди у пользователя через AskUserQuestion:
> Найден проект:
> - Метрика: "Название сайта" (ID: 12345, site.ru)
> - Битрикс24: "Группа проекта" (ID: 67)
> Это верный проект?

**Если найдено несколько** — покажи список и предложи выбрать через AskUserQuestion.

**Если не найдено** — попроси ввести counter_id и group_id вручную.

### Шаг 2: Собрать данные

После определения проекта запусти сбор данных:

```bash
python3 .claude/scripts/project_overview/main.py --counter-id <ID> --group-id <ID> --project-name "<название>" --days 30
```

Для произвольного периода:
```bash
python3 .claude/scripts/project_overview/main.py --counter-id <ID> --group-id <ID> --project-name "<название>" --from 2026-01-01 --to 2026-01-31
```

Можно указать только `--counter-id` (без задач) или только `--group-id` (без Метрики).

Скрипт вернёт JSON со всеми данными.

### Шаг 3: Сформировать отчёт

Проанализируй полученный JSON и сформируй отчёт по формату ниже. Добавь собственные инсайты и красные флаги.

### Правила формирования инсайтов

Анализируй данные и выделяй:
- **Красные флаги** (⚠️): падение трафика >10%, рост отказов >5пп, просроченные задачи, CR упал
- **Позитив** (✅): рост трафика, улучшение конверсий, задачи закрываются в срок
- **Наблюдения** (📊): структура трафика, ключевые источники, распределение задач
- **Рекомендации** (💡): что можно улучшить, на что обратить внимание

Формируй 3-5 инсайтов, приоритизируя красные флаги.

### Правила форматирования

- Числа форматируй с разделителем тысяч (пробел): 12 450
- Время на сайте конвертируй в минуты и секунды: 192.5с → 3м 12с
- Проценты округляй до 1 знака: 35.2%
- Тренды с +/- и %: +5.3%, -2.1%
- Статусы задач: 2=Ждёт, 3=В работе, 4=На контроле, 5=Завершена, 6=Отложена
- Если данных по Метрике нет (не передан counter_id) — пропусти секции трафика/конверсий
- Если данных по Битрикс24 нет (не передан group_id) — пропусти секцию задач
- Если в JSON есть поле "errors" — упомяни ошибки в конце отчёта
